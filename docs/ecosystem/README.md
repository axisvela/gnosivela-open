# GNOSIVELA Ecosystem

This directory is the public entry point for partners, connector authors,
benchmark reproducers and compatibility reporting. It supports Phase 4 P4-M4
("ecosystem and validation") without turning GNOSIVELA into a marketplace
operator: listings and certificates are evidence-based and link to source.

## P4-M4 exit gate

The milestone closes when:

1. an external team reproduces the documented baseline; and
2. at least 2 partner connectors or industry packs are listed.

Passing the gate requires evidence, not a logo: repository, version, licence,
tests, and a reproducible report.

## Issue templates

Use the repository issue templates:

- **Partner / connector listing** — new connector, industry pack or service.
- **Benchmark reproduction** — independent GKF-Bench or scale-benchmark result.
- **Connector verification** — real-source verification for core connectors
  (also tracks P4-M1-03).

## Scope

Public ecosystem work lives in this repository (Apache-2.0). Commercial
industry profiles, enterprise connectors and managed delivery remain in
GNOSIVELA-EE and are not listed here.
